# pikapika-juukiizu

3 さいくらいの子ども向けの、よごれた じゅうき（重機）を ゆびで なぞって ぴかぴかにする Web アプリです。

https://aew2sbee.github.io/pikapika-juukiizu/

## あそぶ じかんの せいげん（スリープモード）

続けて遊びすぎないように、遊んだ時間で「おやすみ」します。

- 時間は画面が表示されている間だけ数えます（選択画面・洗う画面・クリア後のどこでも数え、ほかのアプリに切り替えている間やロック中は数えません）。
- 25 分を過ぎても、洗っている途中では止めません。次に車をぴかぴかにした時点で「くるまたちが ねむそう。あと いっかい あらう？」と聞きます。待ち時間の上限はなく、ぴかぴかになるまで待ちます。
  - 「あと いっかい」: いつものボタンに戻り、好きな車を 1 台洗えます。それをぴかぴかにしたら、聞かずにロックします。聞くのは 1 回だけです。
  - 「おやすみ」: すぐにロックします。
- 洗う画面では、ぴかぴかにしたあとも含めていつでも、右上の「おやすみ」ボタンから時間に関係なくロックできます。
- ロック画面では、夜のガレージで最後に洗った車が眠り、「またあしたね」と出ます。右下の「おとなの ひと」から、かけ算（3〜9 × 3〜9）の答えを入れると解除できます。まちがえても罰はありません。解除すると 0 分に戻ります。
- 経過時間・「あと いっかい」を選んだこと・ロック状態は `localStorage` に保存するので、再読み込みしても解除されません。本番と各 PR プレビューは別々に数えます。
- PR プレビューと開発サーバーでは、URL に `?limit=<分>` を付けると上限を短くして試せます（例: `?limit=1`）。本番では効きません。

## Development

```sh
npm install
npm run dev      # http://localhost:5173/pikapika-juukiizu/
npm run build
```

Every pull request gets a preview at `https://aew2sbee.github.io/pikapika-juukiizu/pr-preview/pr-<number>/`. Changes reach `main` only through a reviewed PR.
